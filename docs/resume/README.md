## 💡 面试答题黄金法则

| 法则 | 说明 |
|---|---|
| **结论先行** | 先给一句话结论，再展开细节 |
| **分层展开** | 总 → 分 → 例，避免一上来堆细节 |
| **STAR 讲项目** | 情境-任务-行动-结果，结果务必量化 |
| **权衡意识** | 说清方案 A vs B 的取舍，而非只背答案 |
| **主动延伸** | 答完顺带提「相关的还有…」，展示知识面 |
| **不会就诚实** | 「这块我了解 X，Y 还需要学习」比硬编强 |
